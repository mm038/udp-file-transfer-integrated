# Demonstration videos

[Return to the submission README](../../README.md#demonstrations).

All four demonstration recordings are available below as MOV files. Open or
download each recording to review its corresponding assignment requirement.

The assignment specifies a **5–8-minute recorded demonstration**, or a live
demonstration when specified by the instructor. The recordings are organised by
the four required demonstration points and total approximately **5 minutes
29 seconds**. Individual durations below are rounded to the nearest second.

| Part | Recording | Duration | Demonstration coverage |
| --- | --- | --- | --- |
| 1 | [Natural-language transfer](Successful%20File%20Transfer%20Initiated%20via%20Natural-Language%20Command.mov) | 1:12 | Successful real UDP transfer initiated through a natural-language request, with command acceptance and file verification. |
| 2 | [Packet loss and collected metrics](File%20Transfer%20Under%202_%20Simulated%20Packet%20Loss%20%2B%20Collected%20Metrics%20.mov) | 2:06 | Transfer under controlled 2% packet loss, together with the collected performance and reliability metrics. |
| 3 | [Metrics-grounded LLM explanation](LLM%20Explanation%20Grounded%20in%20Recorded%20Transfer%20Metrics%20.mov) | 1:42 | LLM explanation of a completed transfer, with the underlying recorded metrics available for comparison. |
| 4 | [Invalid-command rejection](Deterministic%20Rejection%20of%20an%20Invalid%20Command.MOV) | 0:29 | Deterministic Java rejection of an invalid command. The accompanying screenshot example requests an invalid 1 ms timeout and shows that no new transfer starts. |
